# RAVI — Editorial Developer Portfolio

A single-page developer portfolio rebuilt from the v0 editorial design: bone-colored paper, Georgia headlines, a hanging ID pass, a periodic-table skill grid, and a lime contact orb.

---

## Design system

- **Bone**: `#f5f3ed`
- **Ink**: `#161615`
- **Muted**: `#7d7a70`
- **Lime accent**: `#d9ff4f`
- **Headlines**: Georgia italic
- **Labels**: monospace

---

## Sections

1. Hero with oversized `RAVI / MCA` watermark, arched portrait, and Explore work
2. About with hanging developer ID
3. Periodic-table skills with a live detail panel
4. Featured work showcase plus expandable project rows
5. Credentials + year timeline
6. Moments cards
7. Contact footer with a lime “Say hello” orb

Personal details live in `src/data.js`.

---

## Run locally

```powershell
npm.cmd run dev
```
