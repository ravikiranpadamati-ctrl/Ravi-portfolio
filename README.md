# Ravi Kiran — AI/ML Portfolio

A responsive single-page portfolio built with semantic HTML, CSS, inline SVG, and JavaScript. It features a scrolling hero, professional summary, animated orbital illustration, interactive 3D profile pass, education, skills, projects, certificates, and contact links.

The site is a standalone HTML page; it does not use a React application or CSS framework.

---

## Run locally

```powershell
npm.cmd run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production

```powershell
npm.cmd run build
npm.cmd run preview
```

The production site is generated in `dist/`.
